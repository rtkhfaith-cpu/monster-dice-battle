## Tone checklist

- Modern, post-internet, emotionally sincere — **not** generic medieval fantasy
- Monsters: funny, tragic, weird, lovable
- Threat: **The Noise** (algorithmic / emotional corruption)
- Player: **Handler** with bond **Resonance**
