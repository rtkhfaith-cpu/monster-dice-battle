# Echo Links — Assist / Friend System Lore

## In-world name

**Resonance Assist Protocol (RAP)**

## What is an Echo Link?

When a monster bonds deeply with a Handler, it leaves a psychic imprint in local **Signal Soil**—especially after boss battles or near Ladder checkpoints.

This imprint is an **Echo Link**.

## How borrowing works

1. A friend clears a boss → Echo Link deposits in the **Ladder Registry**
2. You reach the same region node → synchronize via **Resonance Signal**
3. The monster manifests as an **Assist Echo** (not a full copy—intentional limit)
4. Echoes cannot stay permanently; instability rises near high Noise floors

## Why the Guild allows it

**Handler Guild Rule 12-C:** “Shared survival increases authentic signal.”

The Ladder **tolerates** Assists because it studies bond patterns for The Core Feed.

## Risks

- Overuse attracts **Viral Swarm** scouts
- Echo may carry friend’s emotional residue (roleplay / buff flavor)
- Noise counterfeits Echo Links — **“Fake Friend Patch”** (seasonal event)

## Emotional core

You are never truly alone in the tower—but every assist is proof someone else struggled on the same floor.

## UI fiction

- Assist select screen = **Signal Soil sync**
- Cooldown = **Echo stabilisation**
- Friend list = **Registered Handlers in your mesh**
