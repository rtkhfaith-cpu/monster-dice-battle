# Visual Art Direction

## Core style: “Cute Cinematic Chaos”

- **Fake-3D:** layered 2.5D arenas, soft depth, parallax
- **Not primary pixel art** — chunky stylized characters, clean outlines
- **Silhouette-first:** readable on phone; one gag shape + one body shape

## Lighting

| Act | Lighting |
|-----|----------|
| Floors 1–8 | Neon rim, greasy bounce, mall fluorescents |
| Floors 9–16 | Screen glow dominates shadows |
| Floors 17–24 | High-contrast static; emotional regions use color weather |
| Floor 25 | UI chrome becomes architecture; refresh-icon sky |

## VFX

- Hits: squash-stretch, sticker particles, emoji-adjacent bursts (original designs)
- Crits: golden “viral” burst + brief frame freeze
- Noise corruption: JPEG artifacts, UI popups, compression ghosts

## UI identity

- **Cursed mobile app** × arcade cabinet
- Rounded cards, sticker badges, fake notifications as lore UI
- Ladder map = vertical **feed** metaphor (foreshadow Core Feed)

## Monster design rules

1. Evolution = **emotional maturity**, not only bigger spikes
2. Noise-corrupted variant: static edges, wrong colors, extra eyes (screens)
3. Stabilized variant: warmer aura, cleaner outline (player bond reward)

## Boss presentation

1. Arena transform before boss spawn (30s intro target)
2. Fake loading screens / terms pop-ups / subscriber HP where thematic
3. Phase shift = environmental storytelling (jingle → minor key, lights dim)

## Ladder progression visuals

- **Hub:** Handler crash-pad apartment; monster stickers on fridge
- **Floor doors:** region icon + daily mutation streak counter
- **High floors:** UI chrome cracks; reality compression visible at edges
- **Floor 25:** infinite scroll pit as background geometry

## Color palette (align with `utils/artDirection.js`)

- Sky pastels + ink outlines (`ART.skyTop`, `ART.outline`)
- Panel UI: white fill, chunky borders (`ART.panelFill`, `ART.panelBorder`)
- Danger/crit: coral + gold (`ART.danger`, `ART.crit`)
- Dock: dark navy + orange accent (`ART.dock`, `ART.panelAccent`)

## Reference tone board

Pokemon (collectibility) · Adventure Time (weird sincerity) · Palworld (cute chaos) · Fall Guys (soft 3D) · Undertale (boss sincerity) · Modern meme UI (ironic, not copyrighted assets)
