# Game audio assets (replace placeholders)

Drop **MP3 or WAV** files here. The audio manager tries to load these paths on web (`/assets/audio/...`). If missing, synth fallbacks play until you add real files.

## Music (`music/`)

| File | Use |
|------|-----|
| `battle_base_loop.mp3` | Normal battle loop |
| `battle_tension_loop.mp3` | Either fighter below 50% HP |
| `battle_danger_loop.mp3` | Player below 30% HP |
| `victory_sting.mp3` | Win screen |
| `defeat_sting.mp3` | Loss screen |

## SFX (`sfx/`)

| File | Use |
|------|-----|
| `ui_click.mp3` | Buttons / menus |
| `battle_start.mp3` | Battle intro |
| `hit_light.mp3` | Normal hit impact |
| `hit_heavy.mp3` | Heavy attack |
| `hit_crit.mp3` | Critical hit |
| `defend_shield.mp3` | Shield up / block |
| `fly_whoosh.mp3` | Fly lunge wind-up |
| `water_splash.mp3` | Water skills |
| `fire_blast.mp3` | Fire skills |
| `metal_clang.mp3` | Metal slash |
| `bacteria_squish.mp3` | Poison / bacteria |
| `egg_crack.mp3` | Egg bomb |
| `poop_splat.mp3` | Splat attacks |
| `level_up.mp3` | Level up (optional) |
| `coin.mp3` | Coin reward (optional) |

Target mix: **BGM 25–35%**, **SFX 80–100%**, **UI 50–70%**.
